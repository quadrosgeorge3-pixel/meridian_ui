System Architecture (4 Tiers):
1. Data Layer

Ingests OpenStreetMap (OSM) spatial primitives via Overpass API with local boundary clipping for Kurla (L-Ward).

2. Optimization Engine

Custom Python/JS graph engine computing Minimum Spanning Trees (MST) & weighted Dijkstra routing with community penalties.

3. Rendering Layer

CesiumJS / Flat-shaded CAD geometry running smoothly at 60 FPS on consumer laptops without dedicated GPUs.

4. Community Layer

Versioned attributable overlays with anti-brigading trust weighting and clipping planes for inferred underground utilities.
